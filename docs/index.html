Como o desconto real é calculado

Preço normal é a mediana dos menores preços diários dos últimos 90 dias, sem contar a última semana, para que a própria promoção não entre na conta. O histórico junta as coletas deste site com cópias antigas das páginas das lojas no Internet Archive. Desconto real é quanto o preço de hoje está abaixo do normal.

Preços no Pix ou à vista, coletados de hora em hora na KaBuM!, Pichau, Terabyte e Amazon. Componentes visuais adaptados de Ovio (MIT).
